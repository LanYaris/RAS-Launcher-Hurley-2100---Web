关于 RAS Launcher

RAS Launcher 是 SphereStudio 开发的一款图形化恒星演化模拟器。它的核心基于经典的 SSE (Stellar Structure and Evolution) 解析公式库。

核心技术

  • 前端 UI：纯 HTML + CSS + JavaScript
  • 计算引擎：SSE Fortran 77 源码编译至 WebAssembly (WASM)
  • 工具链：f2c + Clang (Emscripten)
  • 运行环境：完全在浏览器内运行，无需任何后端服务器

背景与致谢

SSE 模型由 Jarrod Hurley、Onno Pols 和 Christopher Tout 在 2000 年开发。相关论文发表于 MNRAS (2000, 315, 543)。

界面设计参考了伊利诺伊大学 Digital Demo Room 的视觉风格与参数设定。
